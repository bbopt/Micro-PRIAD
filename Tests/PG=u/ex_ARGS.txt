# This is an example of what your ARGS.txt file should look like. In the ARGS.txt file, all lines that beggins       #

# chose a default value, you can eighter comment the line or earase it completly. To initialize an argument,         #
# you need to write down the name of the argument to initialize and on the right of the name the value, with a       #

#                                                                                                                    #
# - fidelity: you may give fidelity a reel number between 0 and 1 excluding 0                                        #

# commented line below) (loggingN and loggingPhi works the same but log different information)                       #
#                                                                                                                    #
# - availInterrupter: you may give a boolean 0 or 1, this control if a intermediate returen is done before entering  #
#   ElectricSimulation module.                                                                                       #
#                                                                                                                    #

#                                                                                                                    #
# - first_s_to_one: you may give a boolean to set this otpion it set the size of the fist group of the MC loop to 1. #
#                                                                                                                    #

#                                                                                                                    #
# - Interrupter: you may give two arguments that are the two folowing, argument for the Interrupter Function are     #

#	* the first argument is the directory of the .jl file containing the customize Interrupter julia function        #
#	* the second argument is the name of the customized Julia function                                               #

#      intermidite return).                                                                                          #
#    + you can also use a builted in Interrupter (printInterReturnConinueEval) that communicate via a .txt file      #
#      with an external algorithm, or simply to see the value of the BB evolv during an evaluation. To call this     #
#      Interrupter, you must give one or two additionnal argument the first one corresponding to the .txt file       #
#      where the intermediate value will be printed and the second one creesponding to the .txt file where the       #
#      algorithme will write true or false to tell the BB to stop the evaluation or continue the evaluation.         #
#      (see examples in the commented lines below)                                                                   #                   
#                                                                                                                    #

# - s: Controls the size of the group evaluated between each subsample and intermediate output.                      #
